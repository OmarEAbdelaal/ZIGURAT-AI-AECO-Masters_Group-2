Logo

The mark is two stacked isometric steps — a ziggurat — split into a blue left face and a green right face on a true 2:1 axonometric slope. The vector version in assets/logo/ was traced from the supplied bitmap and matches it to 98.8% of pixels; the remainder is antialiasing.

Primary mark

zigurat-mark.svg — default. Use on white, off-white or charcoal.

Single colour, reversed

zigurat-mark-mono.svg — one-ink print, watermarks, busy photographic backgrounds. Inherits currentColor.

Team lockup

Mark, rule and two-line signature. Use it on title slides, report covers and the repository README. Keep one step-height (16 units) of clear space on every side; below 180 px wide, drop the text and use the mark alone.

The mark is not ours

The Zigurat name and mark belong to Zigurat Global Institute of Technology. This repository reproduces them for academic use inside the MAICEN Final Master's Project. The lockup above names Group 02 in our own typefaces and must never be presented as official institutional branding. See docs/BRAND-NOTES.md.

Use the semantic tokens, not the raw hexes

Write var(--color-primary), not #1C60F3. The semantic layer is what re-points itself in dark theme; a hard-coded hex will not, and it will be the thing that breaks the night before submission.

Project patterns

Conventions specific to this FMP, so five people producing slides, notebooks and a report separately still produce one thing.

Do

  • Use --series-1…--series-6 in order for chart series, so the same variable is the same colour in every deliverable.
  • Pair every risk colour with its text label or dot.
  • Set BIM parameters, IFC classes and GUIDs in the mono face.
  • Right-align numeric columns and use font-variant-numeric: tabular-nums.
  • Name figures fig-NN-short-slug.svg and keep them vector where possible.

Don't

  • Set mint green text on a white background — it is 1.98:1 and effectively unreadable.
  • Introduce a sixth heading size because a slide felt crowded.
  • Use red/green alone to distinguish two chart series.
  • Paste a hex into a notebook plot; import the token values instead.
  • Stretch, recolour, rotate or add effects to the mark.

Chart series

--series-1 #1C60F3 --series-2 #41CF97 --series-3 #7B4FE0 --series-4 #DD6B20 --series-5 #4A5568 --series-6 #17A2B8

Two series: 1 and 2 — the brand pair. Three or more: continue in order. Beyond six, aggregate rather than adding colours.

Three rules that cover most of it

Colour never carries meaning alone — pair it with a label, icon or dot. Focus is always visible: the shared :focus-visible ring is defined once in components.css, so never write outline: none without a replacement. And motion respects prefers-reduced-motion, which the token file already handles by zeroing both durations.
